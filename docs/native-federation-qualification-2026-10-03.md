## What changed and what remains open

The DataHub fixed query now selects owner URNs through the required CorpUser/
CorpGroup union fragments. Full inventory reads include returned raw schema,
custom properties, source references and ownership metadata. The selection was
checked against the [official DataHub GraphQL schema](https://raw.githubusercontent.com/datahub-project/datahub/master/datahub-graphql-core/src/main/resources/entity.graphql).
Deployments with different schema versions need their own qualification.

dbt records preserve their native content from the exact
[manifest v12 identifier](https://schemas.getdbt.com/dbt/manifest/v12.json).
Generation clocks remain unknown when absent/null; malformed supplied clocks
refuse. Only selected artifact metadata is imported; global `metadata.env` is
excluded. The parser validates the selected identity/version/integrity/budgets,
not the entire JSON Schema or compiled metric semantics. The legacy bounded
import now also refuses UTF-16/32, duplicate keys, non-finite values and invalid
surrogates. The HTTP sample reads bounded regular artifacts without following
symlinks, blocking on FIFOs or accepting a detected change during its read.

Adapter-side paging freezes one bounded captured scope per process. Configuration
and native credential changes invalidate continuation. Restart, a replaced scan,
bad cursor, changed watermark and expiry require a fresh scan. Captured DataHub
reads are a bounded observation sequence, without atomic source-snapshot or fresh
native ACL checks on each continuation. Separate processes are needed for
independent concurrent captures. These limits are documented in the
[operator workflow](native-semantic-adapters.md).

F04 remains open: restricted vendor accounts, permission-qualified documents,
native ACLs and live rotation/drift must still be tested. Estate-scale approved
semantic projection, conflict reconciliation/composition, paired analyst-value
holdouts, cloud/resource/endurance qualification and a signed public release are
independent remaining MVP gates. CI must pass against the PR's current head;
these local results do not substitute for that check.
