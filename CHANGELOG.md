# Changelog

Notable user-visible changes are recorded here. Versions use SemVer; `0.x` releases may change pilot contracts with migration notes. Each release entry must state connector qualifications and known deployment limits.

## Unreleased

- The Python SDK now preserves source policy and refresh provenance, refuses conflicting connection reuse, publishes only already-reviewed snapshots, and binds MCP tools to its own tenant. Catalog translation requires explicit complete scope and preserves unknown provenance; `import_catalog` remains a translation-only compatibility alias.
- Replaced unsupported install/MCP commands, connector snippets and unqualified benchmark/retention claims with executable synthetic examples and the existing self-host flow. SDK examples and all frontend tests now run in Verify; desktop/mobile browser smoke covers developer auth, discovery, review and graph navigation.
- Vite proxies API, authentication and agent routes while preserving the browser origin; small screens start the knowledge map in Records. Initial graph layout separates endpoints and uses standard wheel sensitivity; production bundles keep library runtimes together and use Cytoscape's bundled types. Browser smoke tests exercise both the built UI and the Vite development proxy.
- Demo authentication now exposes an explicit session response; missing auth routes cannot imply steward authority or bypass managed CSRF checks. Shared in-memory SQLite discovery/map reads disable the faulty DBAPI statement cache, with concurrent request regression coverage. SDK publication refuses inconsistent snapshot/readiness responses during refresh or withdrawal.

- Release preparation now reads actual main and protected-environment controls and refuses missing independent review or administrator bypass. The current private Team plan and untested QVL reporting route remain launch blockers; no settings, visibility or subscription change was made.
- A bounded offline collector hashes and parses private archive snapshots and binds wheel/source/npm license texts to exact locks, selected SBOMs and frozen Linux markers. Supplemental publisher texts retain immutable version/source proof bytes for offline revalidation; attestation signatures are not verified. The retained collection covers 415 archives for 414 dependencies, with 265 texts, 39 publisher proof files, eight unresolved notice-text gaps and 20 archive source-pointer gaps. The independent checker refuses the eight; OS/runtime notices, corresponding-source obligations and legal review remain open.
- Temporary runtime cleanup now uses descriptor-safe removal without permission/flag repair, bound to the exact reviewed CPython 3.14.8 source bytes and retained upstream license. Package versions and raw CVE matches remain unchanged; independent disposition and the strict release gates remain unresolved.
- Release manifests now bind an explicit prerelease or stable channel. Stable preparation and publication require aligned >=1.0 production metadata and independent approval of the exact commit in both protected environments. The current 0.1.0 Alpha remains a prerelease.
- Restore validates fixed-size USTAR headers before the archive parser, refusing PAX, GNU and sparse extensions before payload allocation. Qualification drills compare physical migration state against the installed head instead of a stale revision literal and emit content-free failure indexes in CI.
- The pinned PostgreSQL derivative now applies the stable Alpine 3.24 nghttp2 update and records both original and updated package inventories. Its local strict findings decreased from five to four; three offline nonroot/root-refusal controls also verify compressed dump/restore.

Restore rotates browser sessions, rejects partial or changed bundles and requires an explicit app upgrade. External mount backup and customer recovery objectives remain operator responsibilities.
