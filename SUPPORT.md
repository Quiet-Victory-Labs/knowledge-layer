# Support

For usage questions, check the [README](README.md) and [documentation index](docs/README.md), then open a discussion or issue on the repository host with a reproducible synthetic example. Include the version, deployment profile, logs with secrets removed, and the expected result.

Do not post credentials, source records, private documents, or security issues publicly. Use the private route in [SECURITY.md](SECURITY.md) for vulnerabilities.
